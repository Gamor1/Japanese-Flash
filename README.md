**What it is**

Japanese-Flash is a single-file, fully offline practice app for hiragana, katakana, and light extras (numbers, optional words, custom lists).
No install, no account, no internet after you download the file, open it in any modern browser on phone or desktop.

**Modes**

Flashcards - type romaji or the character; weighted review so weak items show up more
Multiple choice - same decks, tap answers
Strings - random kana strings from your selected set (fixed or random length)
Words - built-in vocab + custom lists (hiragana / katakana / custom-only)
Numbers - Arabic (1,2,3) ↔ Japanese readings; kanji or hiragana display; easy / medium / hard / custom ranges

**Features**

Per-mode decks and weights (stored in localStorage)
Infinite practice or one-pass runs with a results screen
Custom kanji in flashcard / multiple-choice setup
Custom word lists: paste (one word per line), import/export JSON, duplicate checks
Themes (presets + custom colors)
Mobile-friendly layout (safe areas, large touch targets, Submit button)
Confetti!

**How to use**

1. Download 
2. Open it in a browser (Chrome, Safari, Firefox, etc.)
3. Optionally add the page to your home screen for app-like use
4. Everything saves on-device; clearing site data resets progress and custom lists

**Custom words paste format**

みず mizu water
コーヒー koohii coffee
たばこ タバコ tabako tobacco

-Seperate kana/romaji/meaning with single space
-Automatically defers Hiragana and Katakana, additionally adds to both if Hiragana and Katakana are given for a single word.
